# Context — `test_ipotesi/` folder

## Purpose

This folder contains the independence tests and exploratory visualizations
run on the **STD calibration dataset** before building the conformal prediction band.
The goal is to verify whether the two key statistical hypotheses required by
conformal prediction are satisfied by the thermal data.

---

## Hypotheses tested

| ID | Hypothesis | Method | Tool |
|----|-----------|--------|------|
| H1 | Layers are mutually independent | ACF + Ljung-Box on layer-mean temperature series | `test_indipendenza.py` |
| H2 | Frames within a layer are mutually independent | ACF + Ljung-Box on T_ROI(t) series per (specimen, layer) | `test_indipendenza.py` |

---

## Scripts

### `test_indipendenza.py`

Main independence test script. For each STD dataset it:

1. Loads the CSV and applies two mandatory filters:
   - `frame_type == 'core'` — discards pre/post-layer frames
   - `roi_complete == True` — discards frames where the ROI extends
     outside the printed part (partial ROI → biased temperature)
2. Runs **Hypothesis 1**: computes layer-mean temperature per specimen,
   plots the ACF up to `MAX_LAGS_LAYER` lags, and runs a Ljung-Box test.
3. Runs **Hypothesis 2**: for every (specimen, layer) pair, extracts the
   frame-level temperature series, plots the ACF, and runs Ljung-Box.
4. Produces a p-value heatmap (specimen × layer) for H2.
5. Saves all results (PNG + TXT) to `risultati/`.

**Key parameters:**

| Parameter | Value | Meaning |
|-----------|-------|--------|
| `TEMP_COL` | `roi_mean_C` | Temperature column analysed |
| `ALPHA` | `0.05` | Significance threshold |
| `MAX_LAGS_LAYER` | `10` | Max ACF lags for H1 |
| `MAX_LAGS_FRAME` | `20` | Max ACF lags for H2 |

**Note on layer indexing:** `layers` are derived per-specimen with
`df[df['specimen']==spec]['layer_index'].unique()`. This avoids empty
cells in the heatmap when two specimens have different layer counts
(e.g., Rec-027_std_2 has 29 layers, Rec-G3_std_1 has 22 layers).

---

### `plot_thermal_drift.py`

Exploratory visualization script. For each STD dataset and each specimen it:

1. Applies the same filters as `test_indipendenza.py`.
2. Aggregates frames to one **mean temperature per layer**.
3. Plots temperature vs. layer index (chronological order), with:
   - Scatter points coloured by layer index using the `plasma` colormap
     (early layers = cool purple, late layers = warm yellow).
   - A **linear trend line** (dashed red) with slope in °C/layer.
   - A **Pearson r** and p-value annotation in the top-left corner.
   - A shared **colorbar** on the right side of the figure.
4. Saves one PNG per dataset to `risultati/thermal_drift_<dataset>.png`.

**Purpose:** to visually confirm (or disprove) the thermal drift detected
by the Ljung-Box test in H1. A positive slope and r ≈ 0.8–1.0 would
indicate a clear warm-up trend that must be modelled before applying
conformal prediction.

---

## Results summary (ROI_wide_2_6_depth_1_2, June 2026)

### H1 — Layer independence

- **Result: REJECTED for all specimens and all ROI configurations.**
- Ljung-Box p ≈ 0.0000 in all 6 cases (2 specimens × 3 datasets).
- **Physical interpretation:** heat accumulates in the printed part across
  layers, causing a monotonic increase in ROI temperature from layer 1
  to the last layer. Layers are NOT exchangeable.

### H2 — Frame independence within a layer

- **Result: largely satisfied.**
- Fraction of layers where H0 is rejected:

| Dataset | Rejections / Total | % |
|---------|-------------------|---|
| ROI_wide_2_6_depth_1_2 | 3 / 51 | 6% |
| ROI_wide_3_7_depth_1_2 | 9 / 51 | 18% |
| ROI_wide_3_10_depth_1_3 | 9 / 51 | 18% |

- Smaller ROI (2×6) shows fewer violations — larger ROIs capture more
  spatial variability across the printed bead, which can introduce
  frame-to-frame correlation.
- **Practical implication:** averaging frames within a layer (to obtain
  one scalar T_mean per layer) is statistically justified.

---

## Implication for conformal prediction

Because **H1 is violated**, raw layer-mean temperatures cannot be used
directly as i.i.d. calibration samples.

**Recommended next step:** fit a trend model
(e.g., linear regression of T_mean vs. layer_index) on the STD data
and work with **residuals**. If residuals pass the Ljung-Box test,
conformal prediction can be applied to the residual space.

The conformal band is then:

```
T_predicted(layer) = trend(layer) ± conformal_margin(residuals)
```

## Path conventions

All scripts use paths relative to `SCRIPT_DIR` (the folder containing
the script itself), so they work regardless of where the repository is
cloned:

```
SCRIPT_DIR  = .../Dataset_giusti/Analisi_dataset/test_ipotesi/
DATASET_DIR = .../Dataset_giusti/creazione_dataset/datasets/
RISULTATI_DIR = .../Dataset_giusti/Analisi_dataset/test_ipotesi/risultati/
```

To add a new STD dataset, add one entry to the `STD_FILES` dict in both
scripts — no other changes needed.
